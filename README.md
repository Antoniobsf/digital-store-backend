# Digital Store — Projeto Final de Back-end

API RESTful desenvolvida em **Node.js**, **Express** e **Sequelize (SQLite)** seguindo o padrão **MVC**, com autenticação **JWT**, **Migrations**, documentação **Swagger** e testes automatizados com **Jest**.

## Tecnologias Utilizadas
- Node.js + Express
- Sequelize ORM + SQLite (com Migrations)
- JWT + Bcrypt.js
- Swagger UI Express (`/api-docs`)
- Jest + Supertest

## Como Rodar o Projeto
1. Clonar o repositório:
    git clone https://github.com/Antoniobsf/digital-store-backend.git
    cd digital-store-backend

2. Instalar dependências:
    npm install

3. Executar Migrations:
    npm run migrate

4. Iniciar servidor:
    npm run dev

5. Aceder ao Swagger: `http://localhost:3000/api-docs`

## Testes Automatizados
    npm test
